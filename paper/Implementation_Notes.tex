\section*{Notes on the new approach to LLM-Adapter integration}

\subsection*{High-level Overview}
\begin{itemize}[leftmargin=1.5em]
    \item Write a thin wrapper around every adapter method I plan to expose.
    \item Design JSON schemas for each wrapper function and publish an OpenAPI spec (I'll maintain a separate function list for compatibility across LLM SDKs).
    \item Implement a small orchestrator that can accept a user goal and run the following simple loop (simulate → validate → execute → observe).
    \item Add logging and basic debug hooks for unit testing.
    \item Iterate on prompts and add few-shot examples for each function.
    \item Create the simulation code for the LLM-Refill example.
    \item Integration testing the LLM-Refill example.
\end{itemize}

\subsection*{Pieces I have}

    \item Simulation code for the LLM-refill example is done.
    \item Integration testing is done for the version of the problem I had implemented. It probably needs to be modified somewhat.
\end{enumerate}
